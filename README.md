# Tasfia Habib Chowdhury — Content Writer Portfolio

A complete responsive HTML/CSS/JavaScript portfolio website focused exclusively on content writing.

## Files
- `index.html` — page structure/content
- `style.css` — responsive design and animations
- `script.js` — subtitle typing animation, mobile menu, reveal animations, contact form behavior

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js`.
2. Replace the sample article titles/descriptions/links with your real writings.
3. Replace the sample B.Sc. project information with your actual projects.
4. Replace the placeholder LinkedIn/GitHub links.
5. Upload the three files to any static hosting service.

The site intentionally does NOT include tutoring experience.
